# MKT_AGREE — 매쓰홀릭 초상권 동의서 웹폼

매쓰홀릭 마케팅 활용 및 초상권 사용 동의서를 웹 폼으로 구현한 프로젝트입니다.
서명은 화면에서 직접 그려서 받고, 제출 데이터는 Google Sheets에 자동으로 쌓입니다.

## 폴더 구조

```
MKT_AGREE/
├── index.html                    # 동의서 폼 화면 (프론트엔드, 이 파일 하나로 동작)
├── google-apps-script/
│   └── Code.gs                   # 구글 시트에 붙여넣을 백엔드 코드
└── README.md                     # 이 파일
```

## 연동 순서 (약 10분)

### 1) 구글 스프레드시트 준비
1. [sheets.google.com](https://sheets.google.com) 에서 새 스프레드시트 생성 (예: `매쓰홀릭_동의서_제출내역`)
2. 상단 메뉴 `확장 프로그램` → `Apps Script` 클릭
3. 편집기에 기본으로 있는 코드를 지우고, `google-apps-script/Code.gs` 내용을 그대로 붙여넣기

### 2) 서명 이미지 저장용 드라이브 폴더 만들기
1. [drive.google.com](https://drive.google.com)에서 새 폴더 생성 (예: `매쓰홀릭_서명파일`)
2. 폴더에 들어가서 주소창 URL의 마지막 부분(`folders/` 뒤 문자열)이 **폴더 ID**
3. `Code.gs`의 `DRIVE_FOLDER_ID` 값에 붙여넣기

### 3) 웹앱으로 배포
1. Apps Script 편집기 우측 상단 `배포` → `새 배포`
2. 유형 선택에서 **웹 앱** 선택
3. 실행 계정: **나**, 액세스 권한: **모든 사용자** ← 이 설정이 꼭 필요합니다 (외부 폼에서 호출하려면)
4. `배포` 클릭 → 최초 1회 권한 승인(본인 구글 계정) 진행
5. 발급된 **웹 앱 URL** 복사

### 4) 프론트엔드와 연결
1. `index.html` 파일을 열어서 아래 줄을 찾는다.
   ```javascript
   const GAS_ENDPOINT = "YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL";
   ```
2. 따옴표 안을 3)에서 복사한 웹 앱 URL로 교체

### 5) 배포 및 확인
- `index.html`을 그대로 더블클릭해서 로컬에서 먼저 테스트 가능
- 실제 서비스로 올리려면 Netlify / Vercel / GitHub Pages 등에 `index.html`을 업로드 (별도 서버 설정 불필요, 정적 파일 하나면 충분)
- 테스트 제출 후 스프레드시트의 `제출내역` 탭에 행이 생기는지, 드라이브 폴더에 서명 PNG가 생기는지 확인

## 시트에 쌓이는 컬럼

| 컬럼 | 설명 |
|---|---|
| 제출일시 | 서버(Apps Script)가 기록한 제출 시각 |
| 성명 / 학원명 / 연락처 | 신청자 기본 정보 |
| 동의여부 | "동의함" / "동의하지 않음" |
| 은행명 / 예금주 / 계좌번호 | 사례금 입금 정보 |
| 사업자등록번호_또는_주민등록번호 | 세금 처리 목적 (아래 주의사항 참고) |
| 서명파일링크 | 구글 드라이브에 저장된 서명 PNG 파일 링크 |

## 주의사항

- **주민등록번호**가 포함될 수 있는 항목이라, 시트 공유 권한을 담당자 최소 인원으로 제한하는 것을 권장합니다. 가능하면 신청자에게 사업자등록번호 입력을 우선 안내하세요.
- `GAS_ENDPOINT`를 실제 URL로 바꾸기 전까지는 제출 버튼을 눌러도 콘솔에 데이터만 찍히고 실제 전송되지 않습니다(안전장치).
- Apps Script 웹앱 특성상 CORS 응답을 직접 받아오기 까다로워 `no-cors` 모드로 전송합니다. 따라서 프론트엔드에서는 "성공/실패 여부"를 서버 응답이 아닌 네트워크 요청 성공 여부로 판단합니다 — 실서비스 전환 시 이중 제출 방지 로직(제출 후 버튼 비활성화)이 이미 적용되어 있습니다.
